\# ⚡ P&G Web Developers

\> Criamos sites modernos, rápidos e focados em resultado para pequenos negócios e profissionais liberais.

Este projeto é uma landing page institucional da \*\*P&G Web Developers\*\*, desenvolvida para simular a apresentação de uma agência de desenvolvimento web.

\---

\## 🌐 Demonstração

O site apresenta:

- Página inicial com proposta de valor
- Página “Sobre / Serviços”
- Seção de diferenciais
- Seção de benefícios
- Layout moderno e responsivo
- Animações suaves de entrada

\---

\## 🚀 Objetivo

O objetivo do projeto é simular uma \*\*apresentação comercial real\*\*, onde o cliente recebe o link do site como vitrine da empresa e entra em contato diretamente para fechar o serviço.

Foco em:

- Conversão de clientes
- Apresentação profissional
- Design moderno e limpo
- Experiência mobile-first

\---

\## 🧠 Público-alvo

Este tipo de site é ideal para:

- Psicólogos
- Clínicas e consultórios
- Profissionais autônomos
- Pequenos negócios locais
- Prestadores de serviço
- Portfólios pessoais

\---

\## 🧰 Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (Intersection Observer API)
- Google Fonts (Inter & Poppins)
- SVG Icons

\---

\## ✨ Funcionalidades

- Layout responsivo (mobile, tablet e desktop)
- Animações suaves ao scroll
- Navegação simples e intuitiva
- Estrutura modular para fácil manutenção
- Design moderno com foco em credibilidade
